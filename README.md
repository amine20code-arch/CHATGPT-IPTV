# IPTV TV Pro 1.1.0

Android TV IPTV client architecture for authorized playlists/providers.

Supports the project paths for M3U, JSON, Xtream Codes, Stalker/Ministra, XMLTV and direct streams. Playback is based on AndroidX Media3 1.11.1.

See docs/FEATURES.md, docs/STALKER.md, docs/PERFORMANCE.md and docs/BUILD.md.

This repository contains source code and build configuration. A signed production APK requires a real Android SDK/Build Tools environment and the developer's private signing key.
